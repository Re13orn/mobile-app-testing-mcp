# 可疑应用行为分析（ADB + 静态审计）

## 目标
对可疑APK进行基础行为审计和静态风险识别，输出取证结论。

## 输入
- APK路径：`/path/to/suspicious.apk`
- 包名（可选）：`com.suspicious.sample`

## 执行流程
1. `file_sha256`：记录样本哈希。
2. `aapt_dump_badging` + `aapt_dump_permissions`：识别权限与安装属性。
3. `aapt_dump_xmltree`：分析组件导出与启动入口。
4. `jadx_validate_apk` + `jadx_decompile_apk`：获取可审计源码。
5. `static_scan_secrets`：查找硬编码C2地址/密钥/凭据。
6. `static_scan_debug_leaks`：查找敏感日志输出。
7. `static_scan_weak_crypto`：查找弱加密与混淆不足。
8. `adb_start_app` + `adb_screenshot`：记录运行初始行为。
9. `adb_shell_command`：采集基础运行状态（如进程/网络连接/日志片段）。
10. 必要时 `adb_pull_file_advanced` 拉取关键文件并 `file_sha256` 固化。

## 输出
- 可疑行为列表（证据级别：高/中/低）
- 潜在恶意能力映射（数据窃取/持久化/远控等）
- 处置建议（隔离、封禁、规则化检测）
