# 应用加壳脱壳分析

分析并脱壳加密保护的Android应用：

## 分析目标
- **APP包名**：`com.protected.app`
- **APK文件**：`/path/to/protected.apk`
- **目标**：识别加壳类型并进行脱壳

## 分析流程

### 1. 加壳识别
- 检测常见加壳厂商特征
- 分析DEX文件结构异常
- 识别加壳保护手段

### 2. 静态分析
- 查看APK结构和资源文件
- 分析manifest文件异常
- 检查native库文件

### 3. 动态脱壳
- Hook类加载器获取原始DEX
- 内存dump提取解密代码
- 重建APK文件结构

### 4. 脱壳验证
- 对比脱壳前后差异
- 验证代码完整性
- 测试脱壳APP运行

## 执行检查清单
- [ ] 使用 `aapt_analyze_apk` 分析APK基本信息
- [ ] 使用 `jadx_decompile_apk` 尝试反编译（可能失败）
- [ ] 使用 `adb_install_app` 安装到测试设备
- [ ] 使用 `frida_list_processes` 查找目标进程
- [ ] 使用 `frida_attach_process` 连接进程
- [ ] 使用 `frida_hook_class` Hook关键类
- [ ] 使用 `frida_dump_memory` 内存dump
- [ ] 使用 `adb_screenshot` 记录分析过程
- [ ] 使用 `file_sha256` 验证文件完整性

## 常见加壳厂商识别

### 1. 360加固保护
- **特征**：`com.stub.StubApp`
- **DEX文件**：classes.dex被加密
- **native库**：`libjiagu.so`

### 2. 腾讯乐固
- **特征**：`com.tencent.StubShell.TxAppEntry`
- **资源**：assets目录下的加密文件
- **native库**：`libtup.so`

### 3. 梆梆加固
- **特征**：`com.secneo.apkwrapper.AW`
- **DEX**：原始DEX被替换
- **native库**：`libsecmain.so`

### 4. 爱加密
- **特征**：`s.h.e.l.l.S`
- **结构**：多个DEX文件
- **加密**：动态解密执行

### Hook ClassLoader
```javascript
Java.perform(function() {
    console.log("[+] 开始ClassLoader Hook脱壳...");
    
    var DexClassLoader = Java.use("dalvik.system.DexClassLoader");
    DexClassLoader.$init.overload('java.lang.String', 'java.lang.String', 'java.lang.String', 'java.lang.ClassLoader').implementation = function(dexPath, optimizedDirectory, librarySearchPath, parent) {
        console.log("[+] DexClassLoader 加载: " + dexPath);
        return this.$init(dexPath, optimizedDirectory, librarySearchPath, parent);
    };
    
    var PathClassLoader = Java.use("dalvik.system.PathClassLoader");
    PathClassLoader.$init.overload('java.lang.String', 'java.lang.ClassLoader').implementation = function(dexPath, parent) {
        console.log("[+] PathClassLoader 加载: " + dexPath);
        return this.$init(dexPath, parent);
    };
    
    // Hook Application
    var Application = Java.use("android.app.Application");
    Application.onCreate.implementation = function() {
        console.log("[+] Application onCreate 被调用");
        this.onCreate();
        
        // 延时dump DEX
        setTimeout(function() {
            dumpDex();
        }, 3000);
    };
});

function dumpDex() {
    Java.perform(function() {
        console.log("[+] 开始dump DEX文件...");
        
        var ActivityThread = Java.use("android.app.ActivityThread");
        var currentApplication = ActivityThread.currentApplication();
        var context = currentApplication.getApplicationContext();
        var classLoader = context.getClassLoader();
        
        // 获取DEX文件路径
        var BaseDexClassLoader = Java.use("dalvik.system.BaseDexClassLoader");
```

## 脱壳后处理
1. **重新打包APK**
2. **修复manifest文件**
3. **重新签名**
4. **功能验证**

## 注意事项
- 不同加壳厂商需要不同的脱壳策略
- 注意保护原始应用的完整性
- 脱壳过程可能需要多次尝试
- 某些加壳可能有反调试保护
