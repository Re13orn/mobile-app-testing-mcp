# 应用加壳识别与反编译可行性分析

## 说明
当前模板聚焦“识别壳特征 + 反编译可达性评估”，不包含运行时脱壳注入。

## 输入
- APK路径：`/path/to/protected.apk`

## 执行步骤
1. `file_sha256`：记录样本哈希。
2. `aapt_dump_badging`：获取基础信息与架构。
3. `aapt_analyze_apk`：综合查看权限、组件、资源信息。
4. `jadx_validate_apk`：验证文件完整性。
5. `jadx_decompile_apk`：尝试反编译。
6. `jadx_get_info`：评估反编译产物完整度。
7. `static_scan_secrets` + `static_scan_weak_crypto`：识别壳相关加载链与保护点。

## 检查清单
- [ ] 反编译产物是否大量空壳/桥接类
- [ ] 是否存在动态加载与反射集中区域
- [ ] 是否存在明显壳厂商特征字符串
- [ ] 关键业务代码是否缺失或高度混淆

## 输出
- 加壳特征与证据
- 反编译可行性结论（高/中/低）
- 后续分析建议（静态深挖方向与人工逆向切入点）
