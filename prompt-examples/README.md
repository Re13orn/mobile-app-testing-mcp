# 📋 Prompt 示例库

这个目录包含了使用移动端App测试MCP进行各种安全分析任务的详细prompt示例。每个示例都提供了完整的分析流程、检查清单和预期输出。

## 📁 可用示例

### 🔓 渗透测试类
- **[Root检测绕过分析](./Root检测绕过分析.md)** - 分析并绕过Android应用的Root检测机制
- **[密码验证Hook分析](./密码验证Hook分析.md)** - Hook登录验证逻辑，分析密码处理流程
- **[SSL证书固定绕过](./SSL证书固定绕过.md)** - 绕过SSL证书固定，实现HTTPS流量抓包

### 🔍 逆向分析类
- **[网络通信加密分析](./网络通信加密分析.md)** - 分析应用的网络通信加密机制
- **[应用加壳脱壳分析](./应用加壳脱壳分析.md)** - 识别加壳类型并进行动态脱壳

### 🛡️ 安全分析类
- **[静态代码安全分析](./静态代码安全分析.md)** - 全面的源码安全扫描和漏洞检测 ⭐ **新增**
- **[恶意软件行为分析](./恶意软件行为分析.md)** - 全面分析可疑应用的恶意行为

## 🚀 使用方法

### 1. 选择合适的模板
根据你的分析目标选择对应的prompt模板。

### 2. 自定义参数
修改模板中的目标信息：
- APP包名或APK文件路径
- 具体的分析需求
- 预期的输出格式

### 3. 提供给AI
将完整的prompt提供给配置了移动端App测试MCP的AI助手。

### 4. 执行分析
AI将自动调用相应的MCP工具完成分析任务。

## 📝 Prompt 结构说明

每个prompt模板都包含以下标准结构：

```markdown
# 任务标题

## 目标信息
- 明确的分析目标
- 输入参数说明

## 分析要求/流程
- 详细的分析步骤
- 技术要求说明

## 执行检查清单
- [ ] 具体的MCP工具调用清单
- [ ] 关键验证步骤

## 预期输出
- 期望的分析结果
- 报告格式要求

## 示例代码/配置
- 相关的技术代码示例
- 配置参数说明
```

## 💡 最佳实践

### 使用提示
1. **环境准备**：确保Android设备已连接且配置正确
2. **权限确认**：确认具有目标应用的测试授权
3. **安全隔离**：在安全的测试环境中执行分析
4. **结果备份**：及时保存分析结果和日志

### 自定义建议
1. **调整参数**：根据具体应用修改包名、文件路径等
2. **扩展需求**：添加特定的分析要求和验证标准
3. **组合使用**：多个模板可以组合使用进行综合分析

## 🔧 技术支持

### 常见问题
- 确保MCP服务器正常运行：`npm start`
- 检查设备连接状态：`adb devices`
- 验证环境配置：`npm run check`

### 扩展开发
如果需要新的prompt模板，请参考现有示例的结构和风格进行创建。
