# 网络通信与加密实现分析（无动态Hook）

## 分析目标
在不依赖动态注入的前提下，评估应用的网络传输与加密实现风险。

## 输入
- APK路径：`/path/to/app.apk`

## 建议执行步骤
1. `aapt_dump_badging`：确认SDK与应用属性。
2. `aapt_dump_permissions`：关注网络相关权限。
3. `aapt_dump_xmltree`（`AndroidManifest.xml`）：查看 `networkSecurityConfig`、导出组件。
4. `jadx_decompile_apk`：反编译源码。
5. `jadx_get_info`：定位主要网络包和安全相关模块。
6. `static_scan_weak_crypto`：识别弱算法与不安全模式。
7. `static_scan_secrets`：识别硬编码证书、公私钥、Token。
8. `static_comprehensive_analysis`：汇总风险。

## 检查清单
- [ ] 是否存在明文HTTP端点
- [ ] 是否存在弱加密（MD5/DES/ECB/固定IV）
- [ ] 是否存在硬编码密钥或证书
- [ ] 是否禁用证书校验/主机名校验（静态证据）
- [ ] 是否有高风险导出组件可触发网络行为

## 输出格式
- 风险项列表（严重度/证据/影响/修复）
- 网络安全基线结论（通过/部分通过/不通过）
- 建议优先整改顺序
